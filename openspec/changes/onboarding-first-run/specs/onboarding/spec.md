# onboarding Specification Delta

## Purpose

首次运行引导能力：在用户尚未完成初始化时主动引导其配置第一个模型厂商，定义首次判定（粘性标记）、两步引导流程、跳过与完成语义、手动重看入口与多主题兼容的行为契约。

## ADDED Requirements

### Requirement: 首次运行判定与自动进入

系统 SHALL 持久化一个初始化完成标记，默认为未完成。标记未完成时应用启动 SHALL 在首帧直接显示引导层（覆盖主界面，主界面不可交互），MUST NOT 出现先渲染主界面再覆盖的闪烁。标记完成后（经由引导完成或跳过置位），后续启动 MUST NOT 自动显示引导。升级兼容：持久化数据缺少该标记但已存在至少一条模型配置时，系统 SHALL 视为已完成，MUST NOT 显示引导。

#### Scenario: 首次启动直接进入引导

- **WHEN** 全新数据（无任何持久化设置）的应用启动
- **THEN** 首帧即显示引导层，主界面被完全覆盖不可交互

#### Scenario: 完成或跳过后重启不再进入

- **WHEN** 用户在引导中完成配置或跳过，之后重启应用
- **THEN** 不再自动显示引导，直接进入主界面

#### Scenario: 已有模型的老数据升级不触发引导

- **WHEN** 持久化数据不含初始化完成标记，但已存在至少一条模型配置（老版本用户升级）
- **THEN** 系统视为已完成初始化，不显示引导

### Requirement: 引导配置流程

引导 SHALL 提供两步：**选择服务商**与**配置**。选择步骤 SHALL 按分组展示预设服务卡片，SHALL 同时提供「自定义连接」与「本地模型」入口（视觉次于预设卡片）。预设服务配置 SHALL 只要求填写 API Key 一项必填信息，模型列表经自动检索以下拉方式选择；静态模型目录 SHALL 离线可用。API Key 检索失败时系统 SHALL 以弱提示降级，MUST NOT 阻断保存。测试连接 MUST NOT 作为完成的门槛。本地模型路径 SHALL 允许不填 API Key 即完成配置。

#### Scenario: 预设服务两步完成配置

- **WHEN** 用户在引导中选择预设服务（如 DeepSeek），粘贴 API Key 后离开输入框，从自动检索出的模型列表中选择一个模型并保存
- **THEN** 配置保存成功，引导完成

#### Scenario: 检索失败仍可保存

- **WHEN** API Key 检索失败（如网络不可用）
- **THEN** 显示弱提示，静态目录模型仍可选择并保存成功

#### Scenario: 本地模型无 Key 完成

- **WHEN** 用户选择「本地模型」，端点预填本地地址，检索或手动填写模型后保存
- **THEN** 无需 API Key 即完成配置

### Requirement: 跳过与完成的语义

跳过入口 SHALL 在引导全程可达。跳过 SHALL 置位初始化完成标记并回到进入引导前的页面。完成 SHALL 保存配置、置位标记并进入「新建审阅」页；当次保存的是首条模型配置时 SHALL 自动成为默认模型。Esc 按键 MUST NOT 触发跳过。

#### Scenario: 首次运行时跳过

- **WHEN** 首次运行的引导中用户点击跳过
- **THEN** 标记置位，落在「新建审阅」页，重启后不再自动弹出

#### Scenario: 手动唤醒后跳过回到原页

- **WHEN** 用户从「设置」页手动唤醒引导后点击跳过
- **THEN** 返回「设置」页

#### Scenario: 完成后落在新建审阅且模型可用

- **WHEN** 用户在引导中保存第一条模型配置
- **THEN** 进入「新建审阅」页，该配置为默认模型，可直接开始审阅

### Requirement: 手动重看入口

设置页 SHALL 提供「重新运行引导」入口以重新进入引导。重看时完成 SHALL 同样保存模型配置；重看时跳过 MUST NOT 改变已完成的标记值。

#### Scenario: 设置页唤醒引导

- **WHEN** 用户在设置页点击「重新运行引导」
- **THEN** 引导层显示，走完整两步流程后可保存新配置

#### Scenario: 重看中跳过不影响标记

- **WHEN** 用户重看引导并跳过
- **THEN** 返回进入前页面，初始化完成标记保持已完成

### Requirement: 引导层主题兼容

引导层 SHALL 在全部 4 个皮肤组合（2 风格 × 明暗）下正确渲染：视觉属性（颜色、圆角、阴影）SHALL 由主题令牌决定，MUST NOT 使用硬编码颜色值；运行中切换风格轴或明暗轴时引导层 SHALL 即时跟随。引导层背景 SHALL 不透明，MUST NOT 透出下层主界面。

#### Scenario: 四皮肤组合渲染一致

- **WHEN** 分别在 4 个皮肤组合下打开引导层
- **THEN** 文本、卡片、边框均可读，视觉属性来自当前皮肤令牌

#### Scenario: 引导中切换主题即时跟随

- **WHEN** 引导层显示时切换主题风格或明暗
- **THEN** 引导层无需重开即呈现目标皮肤

### Requirement: 无模型状态的接续提示

用户跳过引导且不存在可用模型配置时，「新建审阅」页 SHALL 显示内联提示，提供「前往设置」与「重新运行引导」两个去向；存在可用模型配置后提示 SHALL 消失。既有的开始审阅前校验行为保持不变。

#### Scenario: 跳过后新建页显示接续提示

- **WHEN** 用户跳过引导且未配置任何模型，进入「新建审阅」页
- **THEN** 显示含两个去向的内联提示

#### Scenario: 配置模型后提示消失

- **WHEN** 存在可用模型配置
- **THEN** 「新建审阅」页不再显示该提示
