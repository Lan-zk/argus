# review-ui

## Purpose

定义三个页面的界面行为契约。本变更增量：渲染文案面向使用者。

## ADDED Requirements

### Requirement: 文案面向使用者

渲染到页面的全部文案 SHALL 面向使用者，MUST NOT 包含开发侧信息，包括但不限于：版本阶段标识（如 MVP）、需求/规格文档名称与章节编号（如 PRD、§ 引用）、开发进度、设计或原型来源说明。功能提示 SHALL 以使用者可理解的行为语言表述。

#### Scenario: 页面不含文档引用

- **WHEN** 用户浏览任意页面（含提示、说明、标注文案）
- **THEN** 不出现「PRD」「§」等文档引用或「MVP」等版本阶段字样，提示内容描述的是用户可感知的行为

#### Scenario: 行为提示改写

- **WHEN** 某提示原本以「……（PRD §2）」方式注明出处
- **THEN** 改写后仅保留使用者语义（如「本产品是审阅工具，不是编辑器……」），出处信息移除
