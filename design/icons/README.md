# design/icons/ — 图标设计源文件

应用图标的设计源头，产出的 1024×1024 png 经 `npm run tauri icon` 生成 [`src-tauri/icons/`](../../src-tauri/icons/README.md) 全套。

## 文件说明

| 文件 | 职责 |
| --- | --- |
| `argus-minimal.png` | 图标设计稿（源图，用于 `tauri icon` 生成） |
| `argus-minimal.icns` | macOS 图标成品备份 |
| `argus-minimal-prompt.md` | 图标生成/设计说明（设计意图与迭代记录） |
